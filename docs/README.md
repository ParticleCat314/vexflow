## API & Examples

- API reference is generated locally into `docs/api/` with `grunt build:docs`.
- Live examples and tutorials are published at [vexflow.github.io/vexflow-examples](https://vexflow.github.io/vexflow-examples/).

## Which Build Should I Use?

- `vexflow.js`: full build with Bravura, Petaluma, and Gonville bundled
- `vexflow-core.js`: core library with no bundled fonts
- `vexflow-bravura.js`: smaller build with Bravura and Academico bundled
